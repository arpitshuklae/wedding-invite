# Kartik weds Srashti

A digital wedding invitation: a sealed cream envelope with a gold heart wax seal that opens into a watercolor stone-arch invite.

This first slice is the envelope-to-invite experience — no RSVP, auth, or extra pages.

Details come from the family PDF (Kartik & Srashti, 18–19 January 2027, Vrindavan Garden, Bhopal).

## Couple

- **Kartik** weds **Srashti**
- **18th & 19th January 2027**
- **Vrindavan Garden, Bhopal**

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4327](http://127.0.0.1:4327).

Tap or click the gold **K | S** wax seal to break it. The envelope folds away and the invitation is revealed.

```bash
npm run build
npm start
```

`npm start` serves the production build on port 4327.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, and shadcn/ui.
